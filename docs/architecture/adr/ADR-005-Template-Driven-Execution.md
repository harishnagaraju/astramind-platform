# ADR-005

# Template-Driven Execution

Status: Accepted

---

## Decision

Every AI capability SHALL execute from a Template.

Templates SHALL be version-controlled.

Runtime execution SHALL create Workflow Instances from Templates.

Templates SHALL remain immutable during execution.
