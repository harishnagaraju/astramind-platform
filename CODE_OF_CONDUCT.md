# Code of Conduct

## Our Commitment

The AstraMind community is committed to providing a welcoming, professional, respectful, and collaborative environment for everyone.

We value constructive discussions, technical excellence, and knowledge sharing.

---

## Expected Behavior

Community members are expected to:

- Be respectful and professional.
- Welcome different viewpoints and experiences.
- Provide constructive technical feedback.
- Focus discussions on ideas rather than individuals.
- Help maintain a friendly and collaborative environment.
- Respect project guidelines and architectural decisions.

---

## Unacceptable Behavior

Examples of unacceptable behavior include:

- Harassment or personal attacks.
- Discriminatory language or behavior.
- Trolling or deliberately disruptive discussions.
- Publishing private information without permission.
- Abusive or offensive communication.
- Spam or unrelated promotional content.

---

## Technical Discussions

Architecture discussions are encouraged.

When proposing architectural changes:

- Provide technical justification.
- Reference existing Architecture Decision Records (ADRs) where applicable.
- Be respectful of differing opinions.
- Focus on long-term maintainability and engineering quality.

---

## Enforcement

Project maintainers reserve the right to edit, remove, or reject contributions that violate this Code of Conduct.

Repeated violations may result in temporary or permanent exclusion from project participation.

---

## Scope

This Code of Conduct applies to:

- GitHub Issues
- Pull Requests
- Discussions
- Documentation
- Project communication channels

---

## Contact

Questions regarding this Code of Conduct may be directed to the project maintainers through the GitHub repository.

---

Thank you for helping build a professional and welcoming open-source community.
